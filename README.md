# WOLF Local

تطبيق أندرويد يشغّل بوتات Node.js محليًا على الجوال (Node 18 مدمج عبر nodejs-mobile)،
مع تشغيل/إيقاف/جدولة 24 ساعة/سجل مباشر/محرر لملف بيانات الاتصال.

## البناء
1. أنشئ مستودعًا جديدًا على GitHub وارفع محتويات هذا المجلد.
2. تبويب Actions ← Build APK ← Run workflow (أو يعمل تلقائيًا مع كل push).
3. حمّل `WolfLocal-apk` من الـ Artifacts وثبّت `app-debug.apk`.

## تجهيز zip للبوت
- ضع ملفات البوت + `package.json` + مجلد **node_modules** (جاهز، لأن npm غير موجود على الجوال).
- المكتبات يجب أن تكون JavaScript صرف (wolf.js و socket.io-client مناسبة). Puppeteer/Chrome غير مدعوم.
- بعد الرفع اختر ملف التشغيل وملف بيانات الاتصال.

## ملاحظات
- التطبيق يضيف إشعارًا دائمًا (Foreground Service) ويطلب استثناءه من توفير البطارية.
- الجدولة تعمل فقط عند تفعيل زر 🔓 للبوت.
